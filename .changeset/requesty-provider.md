Add Requesty as a supported AI provider. Requesty is an OpenAI-compatible LLM router that exposes many upstream models behind a single endpoint using `provider/model` naming. Configure it with `REQUESTY_API_KEY` and select a model such as `openai/gpt-4o-mini` or `anthropic/claude-sonnet-4-5`.
